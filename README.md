## 🚀 Quick Start / Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/keerthana-rajamani/rportfolio.git
   cd rportfolio
   ```

2. **Run locally**:
   Simply open `index.html` in your web browser:
   ```bash
   # On Windows PowerShell
   Start-Process index.html

   # Or on Mac / Linux
   open index.html   # Mac
   xdg-open index.html # Linux
   ```

3. **Deploy with GitHub Pages**:
   - Go to **Settings** > **Pages** in this GitHub repository.
   - Under **Build and deployment** > **Branch**, select `main` / `root`.
   - Click **Save**. Your live website will be live at `https://keerthana-rajamani.github.io/rportfolio/` in seconds!
